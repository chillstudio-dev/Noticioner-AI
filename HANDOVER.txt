PROJECT
Noticioner AI is a synthetic clinical documentation and practice portal demo. It includes a personal workspace and doctor/practice portal. The practice demo uses local synthetic records; it is not connected to a real hospital identity provider or production patient database.

RUNNING THE DEMO
From the cliniscribe-ai directory run:

  ./scripts/demo-start.sh

Then open http://127.0.0.1:3109/doctor for the doctor portal or http://127.0.0.1:3109/practice for the practice workspace. The script builds when needed and starts the local demo services. App server: port 3109. Local identity: port 4111. Embedded PostgreSQL: port 55433. These services are intended for local loopback demo use.
