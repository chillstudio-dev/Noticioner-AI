# Report fonts

These fonts are embedded and subset into server-generated PDFs. They are distributed under the accompanying SIL Open Font License files.

- `NotoSans-Regular.ttf` and `NotoSans-Bold.ttf`: [notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), Latin report text.
- `NotoSansTamil-Regular.ttf`: [Noto Sans Tamil](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSansTamil), Tamil script shaping.
- `NotoSansCJKjp-Regular.otf`: [Noto Sans CJK](https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/Japanese), CJK and Korean coverage. Regional letterform variants follow this font's Japanese configuration.

Font selection uses Unicode grapheme clusters so combining marks remain with their base characters. No operating-system fonts or runtime font downloads are required.
